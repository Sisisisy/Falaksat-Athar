How the demo model works

For each channel at each station, an eight-nearest-neighbor detector compares measurements with 336 simulated reference samples. It flags distances above a threshold learned from those samples. The shaded band shows the reference minimum and maximum. A flag opens an investigation. Aramco retains responsibility for diagnosis. The scene, contacts and example packet layout are illustrative.
